Embed TrussSketch

Add interactive creative coding backgrounds to any website with just a few lines of code.

Embed in Any Page

Drop a <canvas>, load a pinned loader, and call TrussSketch.mount() with your Lua sketch. Three lines:

<canvas id="canvas" width="600" height="600"></canvas> <script src="https://cdn.trussc.org/sketch@0.6.5.js"></script> <script> TrussSketch.mount('#canvas', luaCode); </script>

The loader boots the engine and runs your sketch on that canvas. mount() returns a Promise that resolves to a controller — see below.

Full HTML Example

Copy this complete example to get started:

<!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <title>My Sketch</title> </head> <body> <canvas id="canvas" width="600" height="600"></canvas> <script src="https://cdn.trussc.org/sketch@0.6.5.js"></script> <script> const lua = ` local t = 0 function update() t = t + getDeltaTime() end function draw() clear(0.05) local w = getWindowWidth() local h = getWindowHeight() setColor(0.3, 0.5, 0.9) drawCircle(w / 2 + math.cos(t) * 150, h / 2 + math.sin(t) * 150, 40) end `; TrussSketch.mount('#canvas', lua); </script> </body> </html>

Controller & Options

mount(target, code, opts) resolves to a controller you can drive at runtime:

const sketch = await TrussSketch.mount('#canvas', lua, { onError: (msg) => console.warn(msg), // build + runtime errors onReady: () => console.log('ready'), }); sketch.run(newLuaCode); // hot-swap the running sketch (returns '' or an error) sketch.pause(); // stop update/draw (saves power) sketch.resume(); sketch.getError(); // current build/runtime error, or ''

opts also accepts cdnBase (where the engine files are served from), files (a { "name.lua": "code" } map of extra Lua files loaded before your main code), and autorun (default true).

One sketch per page. The engine is a single global WebAssembly instance, so mount() can be called only once per page load. Use sketch.run() to change the code, not a second mount().

Version Pinning

Always embed a pinned version so your page keeps working when the engine updates:

<script src="https://cdn.trussc.org/sketch@0.6.5.js"></script> // pinned — recommended <script src="https://cdn.trussc.org/sketch@latest.js"></script> // unstable — testing only

A pinned loader also pins the engine (.wasm/.data) it loads. The @latest alias exists for quick experiments and can change or break at any time — never use it in production.

Alternative: Deploy a Saved Project

Prefer a ready-made page? Export your project from the editor and host the folder as-is:

  1. Save your project from the Sketch Editor (you'll get a .tcsproj file)
  2. Unzip the .tcsproj file — it's a standard ZIP archive
  3. Upload the extracted folder to any static hosting (GitHub Pages, Netlify, Vercel, etc.)
  4. Open index.html — done!

The extracted folder contains:

myProject/ ├── src/ # Your Lua script files ├── data/ # Assets (images, sounds) if any ├── index.html # Ready-to-deploy web page └── truss-project.json # Project manifest (for re-importing into editor)

The index.html loads the TrussSketch runtime from CDN, so no build step is needed. You can also edit the HTML to customize the page layout.
